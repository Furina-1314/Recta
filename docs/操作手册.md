# Recta 矩衡 · 操作手册

本手册按**角色**与**业务流程**组织，逐步说明每一类账务的完整操作。各界面元素的分布与功能总览见 [使用指南](使用指南.md)。

---

## 0. 阅读指引

### 单号体系

| 前缀 | 含义 | 产生时机 |
| --- | --- | --- |
| `REQ-NNNNNN` | 支出提单 | 每次提交支出申请 |
| `INF-NNNNNN` | 入账记录 | 每次确认一笔收入 |

单号全局唯一，可用于搜索、关联与对账。

### 单据状态机

```
             ┌──────────────┐
   提单 ───▶ │  待审理       │
             └──┬───────┬───┘
        核准(可核减)   驳回(必填原因)
             ▼          ▼
      ┌────────────┐  ┌────────────┐
      │  待办结     │  │  已驳回     │──▶ 终态，需重新提单
      └─────┬──────┘  └────────────┘
         办结扣款
             ▼
      ┌────────────┐
      │  已办结     │──▶ 终态，自动生成垫资批复与流水
      └────────────┘
```

- **审批阶段不动账**：核准、核减、驳回都只是资质与额度的认定。
- **办结才扣账**：办结是唯一产生资金变动的动作，以数据库事务保证原子性。
- 谁可以审、谁可以办结，因渠道而异（见各流程中的权限标注）。

### 资金渠道与负责人

| 渠道 | 资金性质 | 审批人 | 办结人 | 入账确认人 |
| --- | --- | --- | --- | --- |
| 灵活公款 | 班级自主资金 | 团支书 | 团支书 | 团支书（增资） |
| 系里报销 | 班委垫付、待系财务核销 | 生活委员 | 生活委员 | 生活委员（核销） |
| 班费平摊 | 每人独立分户 | 团支书 或 生活委员 | 生活委员 | 生活委员（充值） |

## 1. 系统初始化（仅首次，由安装者操作）

1. 双击安装包完成安装；在安装目录放置管理员提供的 `.env.local`。
2. 启动应用，出现**「系统未初始化」**面板。
3. 输入团支书的登录用户名与姓名，点「开立账号并生成临时口令」。
4. **立即抄录临时口令**（只显示这一次）→ 点「我已抄录，去登录」。
5. 用临时口令登录，按提示设置新口令（8~64 位）。
6. 进入「用户」页，开立生活委员与各职能班委的账号，把各自的一次性临时口令线下转交。
7. 进入「分户」页，录入全班同学名单（学号 + 姓名）。

> ⚠️ 团支书与生活委员席位各仅一人在任：开立生活委员后，不能再开第二个；重新启用已停用的席位账号同样受此限制。

## 2. 团支书操作流程

### 2.1 开立班委账号（用户页）

1. 「用户」页 → 开立新账号：填登录用户名（固定不可改）、姓名/职务、选角色 → 「开立账号」。
2. 系统生成**一次性临时口令**，点「复制」后通过可信渠道转交本人。
3. 本人首次登录时会被强制修改口令；此后口令由本人掌握。
4. 忘记口令：选中该行点「重置」，重新生成临时口令转交即可。
5. 人员变动：「停用」保留历史与流水；接任者到岗可「改名」复用账号或开立新账号。

> 账号可停用、可启用，但**永不删除**——所有历史流水与审计记录必须完整保留。

### 2.2 录入分户名单（分户页）

1. 「分户」页 → 同学名单管理 → 输入学号与姓名 → 「＋ 录入」。
2. 姓名有误：点击该同学一行，在右侧输入新姓名「改名」。
3. 名单是班费平摊与充值的前提，请在首次收取班费**之前**录全。

### 2.3 灵活公款增资（账目页）

1. 「账目」页 → 新提单 → 切换「入账登记」。
2. 入账类型选「灵活公款增资」→ 填金额与来源说明（如"校运会评优奖励 500 元"）→ 可附证明材料链接。
3. 「确认提交」。灵活公款余额随即增加。

### 2.4 发起支出提单（账目页 / 审批页）

1. 「新提单」→ 默认「支出提单」。
2. 选出资渠道 → 填动账事项与金额 → 可附证明材料链接。
3. 渠道为**班费平摊**时：勾选参摊同学（可全选）、指定尾差承担人；下方实时预演分摊结果，确认"分项之和 = 总额"。
4. 「确认提交」→ 单据进入**待审理**。

### 2.5 审批（灵活公款单 / 班费单）

1. 「审批」页 → 左侧选中待审理单据。
2. 三种处置：
   - **全额核准**：核准金额 = 申报金额，点「核准出账」；
   - **核减**：把核准金额改小，**必须**填写核减原因；
   - **驳回**：必选预置原因（选"其他"须补充说明），点「驳回」。
3. 核准后单据进入**待办结**；班费单据此时由系统按核准金额重算每个人的分摊。

### 2.6 办结扣款

1. 「审批」页 → 选中待办结单据 → 「确认办结扣款」。
2. 系统自动：扣减对应账户 → 生成每人流水 → 组装办结批复（含垫资明细）→ 单据置为已办结。
3. 办结后可在「账目」页搜索单号查看完整经办记录。

### 2.7 审计看板（审计页）

提单总量、驳回率、核减差额、平均审批/办结响应、常见驳回原因 Top 5，以及每位班委的逐人指标。用于班委会述职与账务复盘。

## 3. 生活委员操作流程

### 3.1 班费集中收取（批量充值）

1. 收到同学的转账后：「账目」页 → 新提单 → 入账登记 → 类型选「同学班费充值」。
2. 填金额（**每人**充入的金额）与来源说明 → 在名单中勾选本批次缴费的同学（可全选）。
3. 「确认提交」——每位勾选同学各生成一条充值流水，透支的同学自动冲抵欠款。
4. 逐笔核对：「分户」页点击同学查看流水；「账目」页搜索单号 INF-。

### 3.2 提单（班费平摊采购，垫付场景）

1. 已替班级垫付采购款：新提单 → 支出提单 → 渠道「班费平摊」→ 填事项与垫付总额。
2. 勾选参摊同学、指定尾差承担人（通常是自己或经办人）→ 确认提交。
3. 提交后把自己垫付的钱收回来靠两件事：同学充值（3.1）或后续班费结余。

### 3.3 审批与办结（系报销垫付流程）

1. 班委先垫钱办事 → 职能班委提「系里报销」单。
2. 生活委员审批：核对票据后全额核准或核减。
3. **办结**：确认垫付事实后点「办结」——系统记为挂账（外部应收），表示"系里欠班费这笔钱"。
4. **核销**：系财务打款到账后 → 「系报」页（或账目页新提单 → 入账登记）→ 选「系报销回款核销」→ 填打款金额与来源 → **必选**关联那张已办结的报销单 → 确认。挂账余额随之减少，两清。

> 核销金额不可超过挂账余额；一分钱挂账对应一分钱应收。

### 3.4 班费单的审批与办结

班费单团支书和你都可以审批，但**办结必须由你执行**——因为透支实质上是你个人垫付，垫资批复会写明每一位欠款同学与金额。

## 4. 职能班委操作流程

1. 首次登录用团支书给的临时口令，立即改密。
2. 「审批」页 → 新提单 → 按事项选渠道提交（买耗材选灵活公款、可报销的打车费选系里报销、全班分摊的选班费平摊）。
3. 在台账中跟踪状态：待审理 → 待办结 → 已办结；若被驳回，按驳回原因补齐材料**重新提单**（旧单已归档）。
4. 本人单据的审批意见与办结批复会显示在详情中。

## 5. 对账与导出

| 要对什么 | 去哪 | 怎么导 |
| --- | --- | --- |
| 全部资金流水 | 账目页（配合类型/渠道/搜索筛选） | 「导出」→ CSV |
| 分户名单与余额 | 分户页 | 「导出」→ CSV |
| 某同学的历次流水 | 分户页选中该同学 | 「导出此流水」→ CSV |

导出文件为 UTF-8 CSV，Excel 双击直开；文件名自动带时间戳。

**月末对账建议**：账目页筛选"已办结"导出一份；分户页导出余额一份；两张表与银行/支付流水三方核对。

## 6. 注意事项速查

- 驳回理由、核减原因、来源说明是**必填**项——它们会进入审计统计，请规范填写。
- 灵活公款**不可透支**：余额不足时办结会被拒绝，先增资再办结。
- 分户可以透支：负数余额 = 生活委员垫付，办结批复自动披露，充值自动冲抵。
- 金额精确到分：输入 `140.00` 这样两位小数，系统不做四舍五入。
- 操作即记账：审批阶段不动账，办结才扣款；每一步都有操作人、时间与不可变流水。
- 测试请用【测试库】实例（`scripts\launch-test.bat` 启动），生产库只记真实账目。
